- Added dynamic DOM manipulation techniques across the application.

- Integrated asynchronous (AJAX) form submission for seamless processing without page reloads.

- Created dedicated Diets and Nutrition pages.

#### Documentation & Technical Notes

- Written complete technical documentation outlining key design decisions and architecture choices.
- Documented project evolution with structured `CHANGELOG.md` updates.
- Updated reference sections and citations inside `README.md`.
- Completed comprehensive inline source code comments across all script and style files.

- Prepped and configured build assets for free hosting platform deployment prior to final submission.
