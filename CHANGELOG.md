# Changelog

All notable updates and milestones for this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-09-19

### What's new in PART 2

#### CSS Styling

- Added unified color palette and global typography.
- Implemented modular stylesheets for layout components.

#### Forms

- Created styled user input fields, textareas, and submit buttons with active/focus states.
- Integrated native HTML5 form validation (`required`, email type checking).

#### Folder Structure

- Reorganized project directories into a scalable architecture (`/css`, `/js`, `/assets`,).
- Separated global styles from page-specific rules.

#### Images

- Added project assets and graphic banners.
- Implemented accessibility features including `alt` attributes across all images.

#### Media Queries

- Added responsive design breakpoints for mobile, tablet, and desktop viewports.
- Adopted CSS patterns utilizing `@media` rules.

#### JS foundation

- Added foundational JavaScript script for interactive components.
